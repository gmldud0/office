# 챙김이

준비물·장보기·여행 체크리스트 웹앱 (HTML·CSS·JavaScript, 서버 없음, 데이터는 브라우저 localStorage).

- v0.1: 에이전트 사무실(Bureau des agents)에서 만든 버전 — 홈, 카테고리, 만들기·수정·삭제, 체크, 진행률, 알림(화면이 열려 있을 때)
- v0.2: 템플릿 7종, 보관함(보관·다시 쓰기·삭제), 설정(알림 권한·알림 테스트·백업 내보내기/불러오기·전체 삭제), 앱 아이콘·manifest(홈 화면에 추가)

알림은 챙김이 화면이 열려 있을 때만 옵니다. 앱을 닫아도 오는 푸시 알림은 서버가 필요해서 아직 없습니다.
