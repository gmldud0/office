# 디자인 참고 메모 (따라 하지 말고 "아이디어만" 가져오기)

사용자가 보고 좋다고 한 다른 계정 게시물에서 뽑은 아이디어. 그림·글꼴·로고·문구를 그대로 베끼지 않는다.

## 2026-11-25 · 정보형 카드 (모눈종이 노트 느낌)
- **안쪽 카드**: 어두운 테두리 안에 둥근 흰 카드, 배경은 **모눈종이 무늬**
- **제목**: 굵은 손글씨 느낌 글꼴 + 흰 테두리 + 그림자
- **항목**: 연노랑 상자 + **점선 테두리**, 번호 매기기 (1. 2. 3.)
- **핵심 숫자**에 손으로 그린 듯한 **빨간 동그라미** (예: "13만 원")
- 장 끝에 **"다음 장에 ▶"** 같은 넘기기 유도
- **댓글 키워드 유도**: "댓글에 [키워드] 남기면 신청 링크 보내 드려요" → 댓글이 크게 늘어남
  - 지금 토큰으로는 댓글에 자동 DM을 보낼 수 없다(권한 추가 필요). 쓰려면 사용자가 직접 답하거나, 나중에 권한을 늘린다.
- 표지는 사진 + 큰 글씨였는데, 사진은 남의 것(저작권)이라 우리는 이모지·직접 만든 그림·우리 앱 화면·사용자가 찍은 사진만 쓴다.

## 쓸 계획
- 3일마다 바뀌는 테마 중 하나를 "모눈 노트" 테마로 추가하는 방안
- 돈·제도 정보 게시물(신청 방법이 있는 것)에서 댓글 키워드 유도 시험

## 2026-11-25 · 공감 시리즈 ("○○들이 스스로 하는 흔한 착각")
- 표지: 큰 사진 + 둥근 테두리 글씨 3줄(마지막 줄만 다른 색) + 생각 말풍선 그림
- 안쪽 장마다 같은 틀: **이름표 스티커**(예: 품종 이름) → **흰 알약 말풍선** "나는 ~라고 생각함" → 아래 검은 띠에 2줄 설명
- 내용이 "정보"보다 "공감·웃음"이라 댓글이 많이 달림 ("우리 집 애도 그럼")
- 우리 버전: 사진 대신 큰 이모지/그림, 주제는 자취생·직장인·사회초년생 등 2030 공감

## 2026-11-25 · 릴스 탭 표지들
- 표지는 대부분 **세로 꽉 찬 그림 + 가운데 큰 글씨 3~4줄**, 줄마다 색을 다르게
- **만화 집중선**(가운데로 모이는 선) 배경 → 시선이 가운데 글씨로 모임
- **납작한 일러스트**(사람·배달 오토바이 등)를 쓴 정보 표지도 조회수 잘 나옴 (예: 산재보험 2.9만)
- 조회수 높은 건 외모·뷰티("얼굴형별 피해야 하는 머리" 120만), 다이소 신상, 생활용품 추천

## 예시로 만들어 본 것
- `시안/예시-게시물/` (6장): 집중선 표지, 공감 카드 3장, 모눈 노트 꿀팁 카드, 댓글 키워드 마지막 장
- 만든 도구: `tools/sian2.mjs`
- 고칠 점: 손글씨 글꼴(개구체)이 가늘고 작아 보임 → 실제로 쓸 땐 더 굵은 글꼴로

## 앞으로
- 디자인은 3일마다 바뀌는 테마에 이 아이디어들을 하나씩 넣는다 (집중선 표지, 모눈 노트, 공감 카드)
- 일주일에 한 번(일요일 밤 작업) 요즘 인기 카드뉴스·릴스 형식을 검색해서 이 파일에 덧붙인다

## 2026-11-25 · 사용자 피드백
- 이모지 **하나만 크게** 두면 밋밋하고 무슨 상황인지 안 보임 ("요리하는 느낌이 아니잖아")
- → **장면으로 만든다**: 배경(주방 타일+조리대, 빨랫줄, 밤 방 창문) + 이모지 여러 개(사람·도구·음식·효과 💦✨🔥) + 말풍선 한 마디("셰프 데뷔?!")
- 사진 대신 그림을 쓸 때는 항상 "상황이 한눈에 보이는가"를 확인

## 2026-11-25 · 실제 사진 쓰기 (사용자: "시각적으로 바로 이해되게, 더 실제적으로")
- 이모지 장면도 "그림 붙여 놓은 느낌" → **실제 사진**을 쓴다.
- 도구: `tools/photos.py` (Openverse = 위키미디어·플리커의 공개 라이선스 사진 검색, 키 필요 없음)
  - `python3 photos.py search "영어 검색어"` → 후보 모아보기 → 눈으로 골라서 `python3 photos.py get <id> <이름>`
  - **CC0 / 공개 도메인 / CC BY만** 쓴다. CC BY는 카드 오른쪽 아래와 캡션 끝에 "사진: 작가 / CC BY 2.0" 표시 (credits.json에 자동 기록).
  - BY-SA, NC(비상업), ND(변경 금지)는 쓰지 않는다.
  - 상표·로고가 크게 보이는 사진, 사람 얼굴이 또렷한 사진은 피한다.
- Pexels는 2026-11 현재 새 API 키 발급이 중단돼 못 씀.
