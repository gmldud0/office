# 에이전트 사무실로 인스타 게시물 만들기 (매주 1번)

## 1. 사무실에 미션 보내기 (복사해서 Max에게 붙여넣기)

```
다음 주 인스타그램 게시물 14개를 만들어 줘. 하루 2개씩 7일 치야.
오전은 월급 관리(통장, 고정비, 저축, 연말정산 같은 것), 오후는 업무 꿀팁(엑셀, 보고, 메일, 회의, 시간 관리)이야.

팀 구성:
- 조사 담당 2명: 하나는 월급 관리, 하나는 업무 꿀팁에서 20~30대 직장인이 요즘 궁금해할 주제 7개씩 찾기.
  숫자·날짜·제도가 들어가면 공식 사이트(국세청, 금융감독원, 마이크로소프트 등)에서 확인하고 출처와 확인 날짜를 남겨 줘.
- 글 담당 1명: 주제마다 캡션과 카드 문구 쓰기.
- 검토 담당 1명: 틀린 정보, 과장, 확인 안 된 숫자가 없는지 마지막으로 확인하기.

결과물은 "posts.json" 파일 하나로, 아래 형식을 정확히 지켜 줘.
{
  "brand": { "name": "단순한 새우", "topic": "월급 · 일 꿀팁", "cta": "팔로우하면 매일 2개씩 받아 봐요" },
  "posts": [
    {
      "id": "YYYY-MM-DD-1-영문소문자-주제",   ← 날짜-순서(1은 오전, 2는 오후)-짧은 영어 이름
      "caption": "첫 줄은 짧고 궁금하게\n\n본문...\n\n📌 저장 유도 한 줄\n\n#해시태그 5~6개 #단순한새우",
      "slides": [
        { "type": "cover", "kicker": "월급 관리 또는 업무 꿀팁", "title": "표지 제목 (줄바꿈은 \n, 강조는 **이렇게**)", "sub": "부제 한 줄" },
        { "type": "list", "num": "STEP 1 (없어도 됨)", "title": "카드 제목", "items": ["항목 1", "항목 2", "항목 3"], "note": "작은 글씨 주의사항 (없어도 됨)" },
        { "type": "list", "title": "카드 제목", "body": "문장으로 설명할 때는 items 대신 body" },
        { "type": "end" }
      ]
    }
  ]
}
규칙: 카드는 게시물마다 4~5장, 한 카드에 항목은 4개까지, 한 항목은 20자 안팎.
캡션은 쉬운 말로, 전문 용어에는 괄호로 한 줄 설명. 출처가 필요한 게시물은 캡션 끝에 출처 링크.
조사 내용과 출처는 "조사노트.md"에 따로 정리해 줘.
```

## 2. 결과를 자동 게시 대기열에 넣기 (Claude Code에게 말하기)

미션이 끝나면 `posts.json`이 미션 폴더(문서 → Bureau des agents → Missions → 이번 미션)에 생깁니다.
`office` 저장소 폴더에서 Claude Code를 열고 이렇게 말하세요.

```
에이전트 사무실 최근 미션의 posts.json을 instagram/content/ 에 이번 주 이름으로 복사하고,
instagram/tools 에서 카드 이미지를 만들어 줘. 미리보기를 보여 주고, 내가 확인하면 커밋하고 푸시해 줘.
```

푸시가 끝나면, 하루 2번 자동으로 올라갑니다.
