# 에이전트 사무실로 인스타 게시물 만들기 (매주 1번)

계정 방향: 「Yozmbom」(@yozmbom) = 복잡한 걸 단순하게 정리해 주는 2030 생활 꿀팁 계정 (한국 전체 대상)

## 0. 사무실 규칙 (사무실 → 「사무실 규칙」 버튼 → 전체 지우고 붙여넣기)

```
# 사무실 규칙

## 나는 누구인가
- 나는 「Yozmbom」(@yozmbom)이고, 인스타그램 정보 계정을 운영해.
- 콘셉트: 복잡한 걸 단순하게 정리해 주는 2030 생활 꿀팁 계정.
- 대상: 한국 전체의 20~30대 (직장인, 자취생, 취준생).
- 주제 바구니 5개: 요즘 유행(음식·장소), 돈(짠테크), 생활(자취·살림), 나 관리(저속노화·건강), 일(업무·AI).
- 목표: 조회수, 저장, 공유(DM)를 늘리는 것.

## 일하는 방식
- 결과물은 모두 한국어로, 쉬운 말로 써 줘.
- 전문 용어를 쓰면 괄호 안에 한 줄 설명을 붙여 줘.
- 조사할 때는 공식 사이트·공식 계정을 먼저 보고, 출처 링크를 꼭 남겨 줘.
- 가격·날짜·숫자·영업시간은 확인한 날짜와 함께 적어 줘.
- 확인 못 한 내용은 지어내지 말고 "확인 못 함"이라고 적어 줘.
- 다른 사람이나 가게가 찍은 사진은 쓰지 마. 사진이 필요하면 "직접 촬영 필요"라고 표시해 줘.
- 협찬·광고 게시물은 없어. 특정 가게를 과하게 칭찬하지 마.
```

## 1. 미션 문구 (매주 「+ 새 미션」 → 날짜만 바꿔서 붙여넣기)

```
조회수를 높이는 게 목표야. 다음 주(2026-12-01 ~ 12-07) 인스타 카드뉴스 14개를 만들어 줘. 하루 2개씩 7일 치야.

바구니별 개수:
- 요즘 유행(음식·장소) 4개: 한국 전체 기준. 지금 줄 서는 디저트·음식, 이번 달 팝업·전시·축제, 지역별 시리즈(서울·부산·대구·대전·광주 등) 같은 것.
- 돈(짠테크) 3개: "몰라서 못 받은 돈", 이번 달에 챙겨야 할 혜택처럼. 세금·제도 숫자는 최대 1개.
- 생활(자취·살림) 3개: 계절에 맞는 꿀팁(겨울 난방비, 연말 정리 등).
- 나 관리(저속노화·건강) 2개.
- 일(업무·AI) 2개: 복사해서 바로 쓰는 AI 질문, 연말 업무 꿀팁 등.

1단계: 트렌드 조사 (조사 담당 3명)
- 한 명: 인스타그램·스레드에서 최근 한 달 동안 저장·공유가 많은 2030 대상 게시물 10개를 찾아서, 주제·첫 줄·형식을 정리해 줘.
- 한 명: 요즘 유행하는 음식·디저트·팝업·전시·축제를 찾아 줘. 가게는 공식 인스타나 네이버 지도에서 위치·가격·영업시간·운영 기간을 확인하고, 확인 날짜를 남겨 줘. 문을 닫았거나 기간이 끝난 곳은 빼.
- 한 명: 커뮤니티(블라인드·더쿠·네이트판 등)에서 요즘 2030이 많이 얘기하는 주제와 유행어를 찾아 줘.
- 결과는 "트렌드조사.md"에 출처 링크와 함께 정리.

2단계: 게시물 14개 (글 담당 1명, 검토 담당 1명)
- 첫 장 제목은 15자 안팎, 궁금하거나 공감되게. 예: "요즘 줄 서는 떡 디저트 5", "몰라서 못 받은 돈 3개"
- 음식·장소 게시물은 카드 한 장에 한 곳씩: 이름, 지역(시·구), 대표 메뉴와 가격, 한 줄 평, 확인 날짜. 캡션에 가게 공식 인스타 계정(@아이디)을 적어 줘.
- 친구에게 DM으로 보내고 싶게 만들어 줘. 캡션 끝에 "같이 갈 친구 태그하기" 같은 한 줄.
- 요즘 유행어는 자연스러울 때만.
- 검토 담당은 사실 확인(가격·기간·영업 여부), 과장, 맞춤법을 확인해 줘.

결과물은 "posts.json" 파일 하나로, 아래 형식을 정확히 지켜 줘.
{
  "brand": { "name": "Yozmbom", "topic": "2030 생활 꿀팁", "cta": "팔로우하면 매일 2개씩 받아 봐요" },
  "posts": [
    {
      "id": "2026-12-01-1-영문소문자-주제",
      "caption": "첫 줄\n\n본문\n\n📌 저장 유도 한 줄\n👥 태그 유도 한 줄\n\n#해시태그 5~6개 #yozmbom",
      "slides": [
        { "type": "cover", "kicker": "요즘 유행 / 돈 / 생활 / 나 관리 / 일 중 하나", "title": "표지 제목 (줄바꿈은 \n, 강조는 **이렇게**)", "sub": "부제 한 줄" },
        { "type": "list", "num": "01 (없어도 됨)", "title": "카드 제목", "items": ["항목 1", "항목 2", "항목 3"], "note": "작은 글씨 (확인 날짜 등)" },
        { "type": "list", "title": "카드 제목", "body": "문장으로 설명할 때는 items 대신 body" },
        { "type": "end" }
      ]
    }
  ]
}
규칙:
- id는 날짜-순서(1은 오전, 2는 오후)-짧은 영어 이름, 소문자·숫자·하이픈만.
- 카드는 게시물마다 4~7장, 한 카드에 항목은 4개까지, 한 항목은 20자 안팎.
- 하루 2개는 서로 다른 바구니로.
```
