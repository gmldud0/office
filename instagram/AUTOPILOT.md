## 1. 무엇을 만들지 정하기
- 한국 시간 기준 **내일과 모레**, 하루 2개씩(`-1-` 오전 11시, `-2-` 오후 6시)이 `instagram/queue/`에 있어야 한다.
- 이미 있는 날짜·순서는 건드리지 않는다. 빠진 것만 만든다. (보통은 모레 2개)
- `instagram/content/*.json`의 기존 주제를 훑어보고 **겹치는 주제는 피한다.**

## 2. 바구니 (5일 주기, 날짜의 일(day) % 5 로 고르기)
| day % 5 | 오전 (-1-) | 오후 (-2-) |
|---|---|---|
| 0 | 요즘 유행 | 생활 |
| 1 | 돈 | 일 |
| 2 | 요즘 유행 | 나 관리 |
| 3 | 생활 | 돈 |
| 4 | 요즘 유행 | 일 |

- **요즘 유행**: 유행하는 음식·디저트가 "뭔지" 설명, 이번 주·이번 달 전국 축제·마켓·전시 일정 정리, 요즘 2030 사이 화제 등. 특정 가게 홍보·가게 사진 금지(DM 허락 전).
- **돈**: 몰라서 못 받은 돈, 이번 달 챙길 혜택, 절약 습관. 세금·제도 숫자는 공식 출처에서 확인한 것만.
- **생활**: 자취·살림·계절 꿀팁.
- **나 관리**: 저속노화·건강 습관 (의학적 단정 금지, "일반적인 생활 습관 정보예요" 한 줄).
- **일**: 업무·AI 활용 (복붙해서 쓰는 형식이 반응 좋음).

## 3. 조사
- WebSearch로 최근 화제·일정을 찾는다. 날짜·가격·장소는 **공식 사이트·공식 발표 우선**, 못 찾으면 기사 기준이라고 카드 note에 적는다.
- 확인 못 한 숫자는 쓰지 않는다. 지어내지 않는다.
- 사이트 직접 열기(WebFetch)는 이 환경에서 대부분 막혀 있다. 검색 결과로 확인한다.

## 4. 원고 쓰기 → `instagram/content/YYYY-MM-DD.json`
형식은 `instagram/content/2026-11-25.json`과 똑같이:
- `brand`: `{ "name": "Yozmbom", "topic": "2030 생활 꿀팁", "cta": "팔로우하면 매일 2개씩 받아 봐요" }`
- `id`: `YYYY-MM-DD-1-영문-주제` (오전) / `YYYY-MM-DD-2-영문-주제` (오후). 소문자·숫자·하이픈만.
- 카드 **8~10장**: `cover` → `list`들 → `end`. 한 카드 항목 4개 이하, 한 항목 20자 안팎.
- **내용은 넉넉하게** (사용자 피드백: 핵심만 있으면 "내용이 부족하다"): 팁 하나마다
  ① 무엇을 하는지 ② **이럴 때**(언제 쓰는지) ③ **➕ 한 줄 더**(응용·업그레이드) 또는 구체적인 예시를 넣는다.
  "왜 필요한지" 카드 1장, "✕ 이렇게 말고 → ○ 이렇게" 비교 카드 1장, "조심할 점" 카드 1장을 되도록 넣는다.
- 보충 정보는 작은 `note`보다 `items`(큰 글씨)로 넣는다. `note`는 확인 날짜·출처·주의 한 줄에만.
- 좋은 예: `instagram/content/2026-11-25.json`의 두 게시물(AI 질문 5개, 책상 습관 5개 — 둘 다 10장).
- **사용자 요청(2026-11-24): 앞으로 모든 게시물을 이 방식으로.** 설명할 거리가 있으면 항상 이렇게 넉넉하게 쓴다.
  주제 자체가 짧은 경우(일정 정리 등)에만 장수가 적어도 괜찮다.
- **표지는 "큰 그림 + 큰 글씨" 스타일**(2026-11-26부터, 사용자 요청: 눈에 확 띄게). 표지 슬라이드 형식:
  `{ "type": "cover", "kicker": "하루 종일 앉아 있다면", "title": "**거북목**\n탈출 습관", "emoji": ["🐢","💻","🪑","🚶"] }`
  - 화면 위쪽 절반에 `emoji[0]`이 아주 크게, 나머지 3개는 작게 둘레에 놓인다. **emoji[0]은 주제를 한눈에 보여 주는 것**으로. (📅처럼 날짜가 찍힌 이모지는 피한다)
  - 앱 화면 등 **우리가 가진 이미지**가 있으면 emoji 대신 `"src": "assets/…png"`.
  - `title`: **2줄, 한 줄 5~6자 이내**(짧을수록 글씨가 커짐). 핵심 단어 하나를 `**강조**`(노란색).
  - `kicker`: 제목 위 한 줄(12자 안팎) — 공감·상황. `sub`는 안 보인다(쓰지 않아도 됨).
  - (보류 — 사용자가 "이제 하자"고 할 때부터) 실제 사진이 더 잘 보이는 주제(음식·물건·장소)는 `tools/photos.py`로 무료 라이선스 사진을 찾아 `"src": "assets/photos/이름.jpg"`로 넣는다 (규칙은 `디자인-참고.md`의 "실제 사진 쓰기"). CC BY 사진은 캡션 끝에 출처 한 줄.
  - 다른 사람·가게·연예인·캐릭터 사진은 절대 쓰지 않는다 (출처를 적어도 허락 없이는 저작권 침해).
- **마지막 장은 공유·댓글 유도**: `{ "type": "end", "title": "거북목 친구한테\n**보내 주기** 🐢", "sub": "저장해 두고 내일부터 하나씩", "ask": "하루에 몇 시간 앉아 있어요?\n댓글로 알려 주세요" }`
  - `title`은 "○○한테 보내 주기 / 단톡방에 공유"처럼 **보낼 사람**을 떠올리게. `ask`는 누구나 한 줄로 답할 수 있는 쉬운 질문.
- 캡션: 짧은 첫 줄(사람들이 **검색할 말** 포함) → 본문 → `📌 저장 유도` → `📤 공유 유도(누구한테 보낼지)` → `💬 댓글 질문` → 해시태그 3~5개, 마지막은 `#yozmbom`.
- 한국어, 쉬운 말, 전문 용어는 괄호로 한 줄 설명. 유행어는 자연스러울 때만.

## 5. 카드 만들기와 확인
```bash
cd instagram/tools && node render.mjs ../content/YYYY-MM-DD.json   # queue/ 에 JPEG 생성, 디자인은 날짜로 자동 선택(3일마다 바뀜)
python3 reel.py ../queue/YYYY-MM-DD-1-… ../queue/YYYY-MM-DD-2-…      # 같은 카드로 릴스 영상(reel.mp4)도 만든다
```
- 카드 게시물이 올라갈 때 릴스도 함께 올라간다. 인스타가 격자에도 보여 주므로 사용자가 앱에서 직접 숨긴다.
- 릴스에는 **배경음악을 넣지 않는다**(사용자 요청). `tools/bgm.py`는 나중에 쓸 수 있게 남겨 둔 것.
- 만든 카드를 montage로 한 장에 모아 **직접 눈으로 확인**한다: 글자 넘침·잘림, 오타, 사실.
- 문제가 있으면 원고를 고치고 다시 만든다.
